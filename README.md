# IMIFI-template (Typst)

Шаблон презентации ИМиФИ для **Typst**.

Цель создания данного репозитория: внедрение системы вёрстки Typst в ИМиФИ как возможного инструмента создания документов.

В файле `imifi-lib.typ` находятся полезные функции для создания презентаций, исходник самого шаблона: `imifi-template.typ`.

В файле `abstract.pdf` Вы сможете найти базовые сведения о том, как верстать простые документы в Typst.
Исходник этого файла: `abstract.typ`.
